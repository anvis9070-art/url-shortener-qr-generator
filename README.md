# 🔗 URL Shortener & QR Code Generator

A simple **Python command-line application** that can shorten URLs, generate QR codes, and maintain a history of shortened URLs.

## ✨ Features

* 🔗 Shorten long URLs using TinyURL
* ✅ Validate URLs before processing
* 📱 Generate QR codes for URLs
* ⚡ Automatically generate a QR code for a shortened URL
* 📜 Save shortened URL history
* 👀 View previously shortened URLs
* 🖥️ Interactive command-line menu
* ⚠️ Error handling for invalid input and processing errors

## 🛠️ Technologies Used

* **Python**
* **PyShorteners** — URL shortening
* **QRCode** — QR-code generation
* **Regular Expressions** — URL validation
* **Datetime** — Timestamp generation
* **File Handling** — URL history storage

## 📋 How It Works

When the program starts, it displays an interactive menu:

```text
==============================
   URL SHORTENER & QR GENERATOR
==============================
1. Shorten URL
2. Generate QR Code
3. View URL History
4. Exit
==============================
```

### 1️⃣ Shorten URL

Enter a URL and the program:

1. Adds `https://` if required.
2. Validates the URL.
3. Sends it to TinyURL through the `pyshorteners` library.
4. Displays the shortened URL.
5. Saves the original and shortened URLs to the history file.
6. Generates a QR code for the shortened URL.

### 2️⃣ Generate QR Code

You can enter any valid URL and generate a QR-code image.

The generated file uses a timestamp-based filename such as:

```text
qr_code_20260923_060000.png
```

### 3️⃣ View URL History

The program stores previous URL conversions in:

```text
url_history.txt
```

The history contains the original URL and its shortened version.

### 4️⃣ Exit

Select option `4` to safely exit the application.
